# Görseller

Gerçek fotoğrafları bu klasöre koyun:

- `dilber-ogretmen.jpg` — kare portre, tercihen 800×800 px
- `ders-ortami.jpg` — ders alanı/tahta fotoğrafı
- `og-default.jpg` — 1200×630 sosyal paylaşım görseli (isteğe bağlı)

Fotoğraf ekledikten sonra `src/data/site.ts` içindeki `photo` alanını güncelleyin:

```ts
photo: '/images/dilber-ogretmen.jpg',
```

Stok fotoğraf kullanmayın. Öğrenci fotoğrafları için yazılı veli izni olmadan yayınlamayın.
